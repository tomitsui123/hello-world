# Hello World

A simple Hello World program written in Python.

## Description

This repository contains a basic Hello World program that demonstrates the fundamental concept of programming by printing "Hello, World!" to the console.

## How to Run

1. Make sure you have Python installed on your system
2. Clone this repository:
   ```bash
   git clone https://github.com/tomitsui123/hello-world.git
   ```
3. Navigate to the repository directory:
   ```bash
   cd hello-world
   ```
4. Run the program:
   ```bash
   python hello_world.py
   ```

## Output
When you run the program, you should see:
```
Hello, World!
```
